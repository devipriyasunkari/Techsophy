# Automated Infrastructure Cost Optimization Tool

A Python-based tool that analyzes cloud usage patterns and suggests cost-saving strategies using AI/ML.

## 🔧 Features
- Simulated cloud usage monitoring
- Anomaly detection using Isolation Forest
- Optimization suggestions
- Modular architecture

## 📦 Requirements
- Python 
- pandas
- scikit-learn

## 🚀 How to Run
```bash
pip install -r requirements.txt
python main.py
